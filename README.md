# ナノ光ファイバ作製条件マネージャー (Nanofiber Fabrication Manager)

ナノ光ファイバ（テーパーファイバ）の作製条件の記録・管理と、透過率データの解析・可視化を一元管理できるデスクトップ＆Webアプリケーションです。

---

## 主な搭載機能

1. **モニタ写真から作製条件を自動抽出 (AI OCR)**:
   - `G:\マイドライブ\parameter photo` にスマートフォンの写真やスクショを入れると、アプリが自動検知。
   - iPhone（HEIC/HEIF形式含む）の写真にも完全対応。
   - Google 最新のマルチモーダルAI（`Gemini 3.8 Flash`）が、液晶モニタの写真から以下の作製パラメータ表を自動抽出します：
     - **加熱電流 I (A)**
     - **延伸速度 v (µm/s)**
     - **開始時刻 t_start (s)**
     - **終了時刻 t_stop (s)**
     - **延伸量 ΔL (mm)**
   - 抽出された条件は表エディタで直接編集可能。ステップ数の増減調整にも対応しています。

2. **規格化透過率（初期受光強度基準 100%）グラフの自動生成**:
   - 透過率CSVデータ（時間 t, 受光強度 V）を読み込み。
   - **初期受光強度 $V_0$ を基準（100%）とした規格化透過率 $T / T_0$（%）** に自動変換してグラフ化。
   - **多段階延伸ステージのオーバーレイ機能**:
     各延伸ステップ（加熱電流、延伸速度、延伸時間帯）をグラフ背景に色分け・注釈表示。どの延伸段階で光損失が発生したかを直感的に把握できます。
   - 初期受光強度 $V_0$、最終規格化透過率 $T_{\mathrm{final}}$、最小透過率 $T_{\mathrm{min}}$、光学挿入損失 (dB) を自動算出。

3. **同一作製条件での実績 ＆ 歩留まり自動集計**:
   - レシピ名や延伸パラメータの一致判定により、同条件で作製した過去サンプルを集計。
   - 作製歩留まり（未破断率）、高透過率歩留まり（$T \ge 80\%$）、平均最終透過率、平均光学損失をリアルタイム表示。

4. **iPhone・スマホ対応 ＆ リモート起動ポータル (Port 8500)**:
   - 同一Wi-Fi環境からiPhone等のスマホブラウザで即座にアクセス可能。
   - **iPhoneからサーバーを立ち上げ可能**: PCの前にいなくても、iPhoneで `http://<PCのIP>:8500`（または `/start`）を開くだけで、Streamlitサーバーを遠隔起動・再起動・停止できます。
   - **ホーム画面に追加（Webアプリ化）**: Safariの共有メニューから「ホーム画面に追加」することで、ネイティブアプリのように1タップで起動可能。
   - **PC起動時の自動バックグラウンド待機**: `setup_autostart.bat` を1度実行するだけで、PC起動時に自動で待機状態となり、iPhoneからいつでも即座に利用可能になります。
   - サイドバーに接続用QRコードを常時表示（カメラで読み取るだけで接続）。
   - モバイルSafari向けのタッチ操作最適化、KPI 2×2グリッド表示、入力ズーム抑止などを完備。

5. **複数サンプルの規格化透過率比較**:
   - 異なる作製条件で作製した複数サンプルの透過率曲線を重畳比較可能。

## 起動方法

### 方法1: iPhone / PC 両対応リモートランチャー（推奨）
1. **`setup_autostart.bat`** を1回実行:
   - PC起動時にバックグラウンドで自動待機するように設定されます（黒い画面は出ません）。
2. **iPhoneから操作**:
   - ブラウザ（Safari）で **`http://<PCのIP>:8500`** を開きます。
   - 「サーバーを起動する」をタップすると、サーバーが立ち上がり自動でアプリ画面へ遷移します。
   - ホーム画面に追加しておくと、次回から1タップで起動できます。

### 方法2: PCから通常起動
- フォルダ内の **`run_app.bat`** をダブルクリックすると、PC画面上でブラウザが開きアプリが起動します。

### 方法3: サーバーを停止したいとき
- **`stop_all.bat`** をダブルクリックすると、稼働中の全サーバープロセスが安全に停止します。

## 初期設定

1. **Google ドライブのフォルダ連携**:
   - デフォルトで `G:\マイドライブ\parameter photo` を監視します。
   - パソコン版 Google ドライブを導入し、上記フォルダに作製条件の写真（.jpg, .png, .heic など）を入れてください。
   - フォルダパスはアプリのサイドバーからいつでも変更可能です。

2. **Gemini API Key**:
   - サイドバーの「Gemini API Key」入力欄にキーを入力するか、Windowsの環境変数 `GEMINI_API_KEY` を設定してください。
   - [Google AI Studio](https://aistudio.google.com/) から無料で取得可能です。

## ファイル構成

- `app.py`: Streamlit アプリ本体（UI・可視化・登録）
- `vision_extractor.py`: Gemini 3.8 Flash による条件写真の解析・表抽出モジュール
- `transmittance_analyzer.py`: 透過率CSVのパース・100分率正規化・Plotlyグラフ描画モジュール
- `folder_watcher.py`: `G:\マイドライブ\parameter photo` のスキャン・監視モジュール
- `database.py`: 作製履歴の SQLite データベース管理
- `sample_data/`: 動作確認用のサンプル画像・サンプルCSV
- `run_app.bat`: Windows 用起動バッチ
- `requirements.txt`: 必要 Python パッケージ一覧
